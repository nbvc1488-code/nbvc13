# Карьера

Футбольная визуальная новелла о сезонах 1992–1995 на Ren’Py 8.5.3.

## Запуск

Скачайте архив CareerGame-v9.1.2-1992-1995-win.zip из репозитория, распакуйте его и запустите CareerGame.exe.

## Изменения в 9.1.2

- Оклад «Бенфики» составляет $1 500 в месяц, премия за победу — $500. Договор действует с сезона 1995.
- При погашении матчевой дисквалификации между сценами игра сообщает об этом и добавляет запись в историю.
- На просмотре у тренера панель статистики свёрнута по умолчанию.

Проект открывается в лаунчере Ren’Py. Сохранения игрока и локальные кэши исключены из репозитория.
